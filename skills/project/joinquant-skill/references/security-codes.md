# 证券代码格式 + 交易所映射

## 代码格式

聚宽平台使用 `代码.交易所后缀` 格式：

| 交易所 | 后缀 | 示例 |
|--------|------|------|
| 上海证券交易所 | `.XSHG` | 600000.XSHG |
| 深圳证券交易所 | `.XSHE` | 000001.XSHE |
| 中国金融期货交易所 | `.CCFX` | IF2401.CCFX |
| 上海期货交易所 | `.XSGE` | RB2401.XSGE |
| 大连商品交易所 | `.XDCE` | M2401.XDCE |
| 郑州商品交易所 | `.XZCE` | SR401.XZCE |
| 上海国际能源交易中心 | `.XINE` | SC2401.XINE |

## 期货主力合约

- 聚宽使用 `品种代码+年月.交易所` 格式，如 `IF2401.CCFX`
- 主力连续合约使用 `品种代码9999.交易所`，如 `IF9999.CCFX`
- 次主力连续合约使用 `品种代码8888.交易所`

## 与其他平台代码转换

### Tushare → 聚宽
```python
# Tushare: '000001.SZ' → 聚宽: '000001.XSHE'
# Tushare: '600000.SH' → 聚宽: '600000.XSHG'

def tushare_to_jq(code):
    """Tushare代码转聚宽代码"""
    symbol, exchange = code.split('.')
    if exchange == 'SZ':
        return f'{symbol}.XSHE'
    elif exchange == 'SH':
        return f'{symbol}.XSHG'
    return code
```

### 纯数字代码 → 聚宽
```python
# 使用 normalize_code
from jqdata import normalize_code

normalize_code('000001')   # → '000001.XSHE'
normalize_code('600000')   # → '600000.XSHG'
```

**判断规则**：
- 0/2/3 开头 → 深交所 (XSHE)
- 6 开头 → 上交所 (XSHG)
- 688 开头 → 上交所/科创板 (XSHG)
