## 成交规则（实证验证）

| 规则 | 实际行为 | 验证来源 |
|------|---------|---------|
| 成交价 | 09:30 开盘集合竞价价格 | transaction.csv 显示委托时间=09:30:00 |
| 整手交易 | **必须整手（100股）**，不足1手则不买入 | 计算 int(value/price/100)*100 |
| 涨停处理 | 开盘涨停无法买入 | 用 open 价格判断，非 close |
| 跌停处理 | 开盘跌停无法卖出 | 用 open 价格判断，非 close |
| 停牌处理 | 无法交易，持仓保持不变 | — |
| T+1 | 买入当日不可卖出 | closeable_amount 反映 |
| 滑点模型 | FixedSlippage(0.02) = 每股固定0.02元 | — |

## 成本结构（实证验证）

| 费用项 | 金额 | 说明 |
|--------|------|------|
| 印花税 | 卖出金额 × 0.1%（2023-08-28前） | 仅卖方 |
| 印花税 | 卖出金额 × 0.05%（2023-08-28后） | 仅卖方 |
| 佣金 | max(成交额 × 0.03%, 5元) | 买卖双方 |
| 滑点 | 股数 × 0.02元 | 固定每股 |

**实证**：小金额交易（如2000元/笔）时，佣金计算 2000×0.03%=0.6元 < 5元，
实际收取最低佣金5元，成本占比高达0.25%。

## 执行时序（实证验证）

```
月末最后一个交易日 T:
  09:30:00  run_monthly() 被调用
            ├── 读取 T-1 的数据作为信号 (get_trade_days(count=2)[0])
            ├── 计算因子、选股
            ├── order_target() 先卖后买
            └── 以当日 09:30 开盘集合竞价价格成交

整个月持有，直到下一个月末再调仓
```

## order_target_value 详细行为（实证验证）

```python
order_target_value(stock, target_value)
# 内部逻辑：
# 1. 计算目标股数 = int(target_value / price / 100) * 100  (向下取整到整手)
# 2. 如果目标股数 < 100 → 不下单（买不了1手，跳过）
# 3. 如果 price * 100 > target_value → 同上，跳过
# 4. 计算差额 = 目标股数 - 当前股数
# 5. 差额 > 0 → 买入，差额 < 0 → 卖出，差额 = 0 → 不操作
```

**续持行为**：持仓续持时做增量调整（买/卖差额），比每月全部清仓重建更接近等权。

## 资金闲置问题（实证验证）

以 10万本金、50只持仓为例：
- 每只目标金额：10万 / 50 = 2000元
- 股价30元的股票：1手 = 3000元 > 2000元 → 买不了，跳过
- 实际结果：仅持有 ~41只（非50只），**现金占比达28.7%**
- 仅 ~73% 的资金在股票上

**影响**：
- 显著降低收益（实际收益 ≈ 纯因子收益 × 投资比例）
- 降低 Beta（因为部分资金是现金）
- 高价股被系统性跳过，引入非预期的选股偏差

**解决方案**：
- 减少持仓数量（如20只而非50只）
- 增大初始资金
- 选择低价股池

## 股票池过滤最佳实践

在选股时应过滤以下股票：

```python
def filter_stocks(stock_list, date):
    """过滤不可交易或高风险股票"""
    current_data = get_current_data()
    filtered = []
    for stock in stock_list:
        # 1. 过滤停牌
        if current_data[stock].paused:
            continue
        # 2. 过滤ST
        if current_data[stock].is_st:
            continue
        # 3. 过滤涨停（开盘涨停买不进）
        if current_data[stock].day_open >= current_data[stock].high_limit:
            continue
        # 4. 过滤次新股（上市不满60天）
        info = get_security_info(stock)
        days_listed = (date - info.start_date).days
        if days_listed < 60:
            continue
        # 5. 过滤北交所（可选，默认 get_all_securities 不含）
        if stock.startswith('8') or stock.startswith('920'):
            continue
        filtered.append(stock)
    return filtered
```

## 回测参数建议

| 参数 | 建议值 | 说明 |
|------|-------|------|
| 初始资金 | ≥ 50万 | 避免整手约束导致严重资金闲置 |
| 持仓数量 | 20-30只 | 平衡分散与资金利用率 |
| 回测区间 | ≥ 3年 | 覆盖牛熊周期 |
| 频率 | daily | 除非需要日内策略 |
| 基准 | 与策略风格匹配 | 大盘策略用沪深300，小盘用中证1000 |
